# Comparisons with established alternatives

Choose a comparison by the operation you need. Parsing CSV cells, mapping a finite list, selecting HTML links, and
matching a Result branch have established alternatives with overlapping outputs. A resource definition, a fenced queue
claim, and a replayable workflow have additional ownership contracts. A faster array operation does not replace those
contracts.

[The executable fixtures](../tests/fixtures/alternatives.ts) expose named public imports and two implementations per
case. [The tests](../tests/alternatives.test.ts) check each implementation against a separately written expected value;
neither implementation is the expected-output oracle. The focused suite passed its 27 cases on the pinned Deno runner on
2026-10-07. This is a local corpus result, not comprehensive compatibility with any upstream library.

## Versions and upstream contracts

These are the resolved versions used by the comparison fixtures. The lockfiles determine the exact installed graph; some
existing manifest constraints remain ranges. Only p-limit and neverthrow were added as new comparison libraries. The
other parsers, schema engines, framework, and Standard Library packages already participate in repository work. None is
added to the production dependency graph merely to run a comparison.

| Alternative                | Resolved version | Primary contract and comparison reason                                                                                                                                                                                                                                                |
| -------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Compare finite bounded mapping, rather than workflow or resource ownership. |

## Shared inputs and deliberate differences

The fixture catalogue contains fifteen comparisons. Each callable creates fresh per-call output or consumes its owned
response; the immutable input descriptions can be reused. The application route definitions are prepared once, so route
calls include Request creation, dispatch, response creation, and complete JSON consumption. They exclude route setup and
network startup. The mapping fixture creates its limiter per call and collects the complete output.

| Cases                                    | Independent expected output                                                                                | Limits and negative controls                                                                                                                                                                     |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `schema-port`, `environment-record`      | Port `8787`; configuration `{ PORT: 8787, MODE: 'production' }`                                            | Invalid ranges, nonnumbers, and invalid mode reject. Environment field documentation, sources, secrets, and diagnostics remain utility contracts. Error classes differ.                          |
| `timestamp-codec`                        | `2026-01-01T00:00:00.000Z` after wire → Date → wire                                                        | Malformed wire dates and invalid application Dates reject in both directions. Utility schema diagnostics differ from Zod errors.                                                                 |
| `result-branches`                        | `['saved:asset-1', 'reject:missing', 'default']`                                                           | Unexpected callback faults propagate in both implementations; mutable payloads remain caller-owned. The utility freezes its wrapper without recursively freezing payloads.                       |
| `csv-npm`, `csv-std`                     | Two exact three-cell rows, including quoted comma, embedded LF, Unicode, doubled quotes, and leading zeros | Unterminated quoting rejects. Raw alternatives omit document/header metadata, dialect discovery, source occurrences, and utility diagnostics.                                                    |
| `ordered-map-p-limit`, `ordered-map-std` | Ordered values `index * 3 + 1` for inputs 0…31                                                             | Separate promise gates prove at most two active callbacks and all six ordered results. No timer threshold or equivalence of abort, queued-call retirement, or failure ownership is implied.      |
| `html-anchor-targets`                    | `['/guide', '/pricing']` from HTML with unclosed tags and one anchor without href                          | Same parse5 grammar; different traversal/selection and tree adapter. This is not HTML sanitization or CSS selector conformance.                                                                  |
| `css-url-tokens`                         | `['hero.webp', 'brand.woff2']`                                                                             | Same CSS engine. A separate string-valued `@import` case deliberately returns an extra utility resource that a URL-token walk omits.                                                             |
| `sitemap-locations`                      | Entity-decoded query URL and a Unicode CDATA URL in the correct Sitemap namespace                          | Only a small urlset projection. Utility rejects DOCTYPE while Saxes can still read that document's loc. No feed/index, fetch policy, truncation, or safe-DTD equivalence is claimed.             |
| `fetch-route-hono`                       | JSON `{ id: '42' }` from a finite GET route                                                                | The richer [HTTP parity corpus](../tests/http-parity.test.ts) qualifies explicit request, routing, and service cases separately. A one-route example alone cannot justify a router architecture. |
| `utf8-lines`                             | `['snow:雪', 'second', 'last']` across CRLF/LF and one-byte UTF-8 chunks                                   | The native reference collects one whole Response before splitting. Equal lines do not equate streaming retention, backpressure, invalid UTF-8 handling, or cancellation.                         |
| `exact-semver`                           | Release comparison `[-1, 2, 10, 0]` for 2.9.0 versus 2.10.0                                                | Both reject malformed exact versions. Only the utility accepts coarse `2.4` evidence; the exact parser intentionally rejects it.                                                                 |
| `http-json-body`                         | JSON `{ id: 'asset-1' }`                                                                                   | Separate controls show the utility rejects excess bytes and wrong media type while native JSON consumption accepts that type. Complete JSON output does not equate transport policy.             |

A guarded record control also proves that utility snapshotting rejects an accessor before reading it, whereas native
object spread executes the getter. This is an intentional trust boundary, not a parser performance defect.

For benchmarks, use the fixture's `scope` label. `same-engine-adapter` explains the cost of wrapping the same engine.
`shared-output` proves only the output named above; inspect the stated work and ownership differences before
interpreting a ratio. Do not time assertions or interpret this corpus as a throughput threshold. See
[benchmarks](./benchmarks.md) for exact registered programs, retained native reports, scaling, and timing limitations.

## Review of every package family

This inventory was derived from the current package manifests: 41 focused packages and the umbrella package. Existing
cost references were inspected before selecting new libraries. “N/A” means no equivalent established-library operation
is qualified here; it does not assert that no competing project exists. Import/bundle comparisons apply separately to
the published package inventory and do not manufacture a behavioral competitor.

| Family      | Comparison disposition                                                                                               | Boundary                                                                                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| activity    | Existing dispatch/replay workload; equivalent-library N/A                                                            | Declared activity identity, validated inputs, provider invocation, and terminal ownership are not list mapping.                                                                        |
| capacity    | Existing atomic reservation workload; equivalent-library N/A                                                         | A promise limiter does not provide atomic multi-capacity reservation or returned reservation ownership.                                                                                |
| catalog     | Existing native Map cost reference                                                                                   | Static definition lookup and duplicate validation do additional work; Map lookup alone proves no definition identity contract.                                                         |
| codec       | Zod directional codec fixture                                                                                        | Same validation engine, independently expected round-trip value and rejected inputs.                                                                                                   |
| concurrency | p-limit and `@std/async` fixtures                                                                                    | Finite successful bounded ordered mapping; owned cancellation/failure settlement remain separate.                                                                                      |
| context     | Existing child cancellation and joined-cleanup workloads; equivalent-library N/A                                     | Promise and AbortController primitives do not own scoped children and asynchronous cleanup.                                                                                            |
| css         | CSS Tree fixture                                                                                                     | Same engine; direct URL projection excludes richer resource metadata and string imports.                                                                                               |
| csv         | csv-parse and `@std/csv` fixtures plus scaled existing workloads                                                     | Raw string records overlap; headers, source metadata, discovery, and errors differ.                                                                                                    |
| deno        | Existing permission arguments/native-host workloads                                                                  | Runtime permission policy is platform-specific; no portable permission library equivalence is claimed.                                                                                 |
| dispose     | Standard stack protocol tests; equivalent-library N/A                                                                | Pure named local stack bindings do not change globals; `/polyfill` explicitly installs compatibility. Disposal protocol behavior qualifies separately from context/resource ownership. |
| duration    | Existing fixed-duration/anchor workloads and explicit Temporal provider tests                                        | Native Date arithmetic is a primitive reference; fixed milliseconds do not replace calendar-aware durations.                                                                           |
| effect      | Existing declared-effect scope workload; equivalent-library N/A                                                      | A collection helper does not validate effect definitions or own observers and emitters.                                                                                                |
| email       | Existing normalized identity workload; full-policy alternative N/A                                                   | A syntax validator alone would omit address classification, normalization, and application identity policy.                                                                            |
| entitlement | Existing interpreted-entitlement workload; equivalent-library N/A                                                    | Application-owned policy and returned grants need an explicit model before comparison with a policy engine.                                                                            |
| env         | Direct Zod record fixture and existing parse workload                                                                | Same validators; explicit sources and documented/secret fields are extra adapter work.                                                                                                 |
| failure     | Existing trusted failure/wire round-trip workload; equivalent-library N/A                                            | Generic error strings do not supply trusted declared identity or safe serialization.                                                                                                   |
| fault       | Existing bounded fault projection workload; equivalent-library N/A                                                   | Native Error properties do not guarantee safe getter handling, redaction, or bounded diagnostic retention.                                                                             |
| hono        | Existing direct-Hono adapter workload                                                                                | Same framework; middleware/security declarations are additional work.                                                                                                                  |
| html        | Direct parse5 traversal fixture                                                                                      | Same parser engine; selection and adapted tree structure differ.                                                                                                                       |
| http        | Native Request JSON fixture plus HTTP parity corpus                                                                  | Bounded transport and credential forwarding require explicit controls beyond equal JSON.                                                                                               |
| meter       | Existing accepted reading/sink workload; equivalent-library N/A                                                      | A counter library does not automatically share trusted reading identity, timestamp, validation, and sink acceptance.                                                                   |
| permission  | Existing accepted/denied policy workload; equivalent-library N/A                                                     | Permission definitions and application authorization interpretation are not generic object membership.                                                                                 |
| pool        | Existing direct-value cost reference                                                                                 | Direct binding reads omit leases, capacity, validation, shutdown, and disposal.                                                                                                        |
| process     | Existing same-child `Deno.Command` comparison                                                                        | Child output overlaps; capture bounds, cancellation, group retirement, and joined shutdown are additional owner work.                                                                  |
| query       | Existing lossless wire/list and Boolean grammar workloads; equivalent-library N/A                                    | URLSearchParams supplies flat repeated strings, without typed Boolean grammar or supported adapter semantics.                                                                          |
| queue       | Existing FIFO array cost reference                                                                                   | Arrays omit leased claims, expiry, generations, fencing, cancellation, and stored completions.                                                                                         |
| record      | Existing native-copy cost reference and adversarial accessor control                                                 | A plain spread is comparable only for known safe data; it executes accessors that guarded snapshots reject.                                                                            |
| requirement | Existing declared-requirement workload; equivalent-library N/A                                                       | Imported requirement identity and runtime resolution are separate from generic predicate functions.                                                                                    |
| resilience  | Existing bounded policy-plan workload; equivalent-library N/A                                                        | A retry loop alone omits owner/stage identity, idempotency decisions, deadlines, and observer policy.                                                                                  |
| resource    | Existing provider acquisition/disposal workload; equivalent-library N/A                                              | Direct object construction omits trusted definitions, owned acquisition, and joined retirement.                                                                                        |
| result      | neverthrow Ok/Err fixture                                                                                            | Branch projection and fallback overlap; trusted Failure identities and task outcome ownership remain separate.                                                                         |
| robots      | Existing local parsing/matching corpus and discovery workload                                                        | No Google-corpus parity or maintained JavaScript comparator qualification is claimed here.                                                                                             |
| schema      | Direct Zod parse fixture                                                                                             | Same engine; normalized Standard Schema diagnostics and asynchronous adapter behavior add work.                                                                                        |
| server      | Hono Fetch fixture, HTTP parity corpus, and existing independent linear router oracle                                | Only corpus-defined routing/response behavior is equivalent; no deployment/network performance claim.                                                                                  |
| sitemap     | Independent Saxes loc fixture and existing discovery workload                                                        | Historical parser oracle; protocol safety, limits, namespaces, and diagnostics require their own tests.                                                                                |
| streams     | Native finite collection fixture and existing scaled streaming workload                                              | Whole-body collection omits streaming retention and cancellation ownership.                                                                                                            |
| task        | Existing checkpoint/cancellation workloads; equivalent-library N/A                                                   | A promise has no declared expected-failure channel or scoped cleanup owner.                                                                                                            |
| telemetry   | Existing bounded diagnostic/reporting workload; equivalent-library N/A                                               | Logging adapters are observation mechanisms; they do not become task authority or application logging configuration.                                                                   |
| utils       | Existing focused/eager import and installed artifact comparisons                                                     | Umbrella facade has no separate operation to compare to a general-purpose library.                                                                                                     |
| version     | Exact `@std/semver` fixture                                                                                          | Same engine for exact versions; coarse evidence and refinement are deliberately extra capabilities.                                                                                    |
| worker      | Existing real Worker cold/warm request/shutdown workload                                                             | A raw Worker omits validated correlation, owned admission, cancellation, and shutdown. Native host support is explicit.                                                                |
| workflow    | Existing instruction identity, activity dispatch, and Scheduler replacement/replay workloads; equivalent-library N/A | Collection libraries have no instruction history or fencing contract. In-memory replacement is not persisted recovery after process death.                                             |

Lodash and Underscore remain useful collection libraries, but their broad utility label does not make them appropriate
baselines for capability definitions, lifecycle authority, or workflow recovery. A future comparison with a policy,
resource, queue, or workflow system must first define shared persistence, delivery, failure, and retirement behavior,
then run the same independently expected scenario. Adding a large deployment framework only to obtain an unrelated
microbenchmark would not answer that question.
