## Keep the references current

`deno task docs:api` derives these files from package manifests and
[deno doc](https://docs.deno.com/runtime/reference/cli/doc/); `deno task docs:api:check` detects drift without changing
files. Both commands use the installed Deno version. Run `mise install` and `mise run install` first when preparing this
checkout.

`deno task docs:html` also generates a searchable static reference in `.artifacts/docs/html/`. Open its `index.html` in
a browser. Generation does not publish a website.

The Markdown blocks are Deno’s readable notation, so an interface field has its explanation immediately below it. Use
JSON or the declaration source when you need the complete type structure rather than the display notation. In a JSON
file, select `modules["@okikio/activity"].symbols`, for example, to inspect the exported activity declarations.

Runtime validation still uses the supplied schemas. A TypeScript declaration alone does not validate a value from a
request or persisted record, and generating documentation does not change the runtime’s contracts.
