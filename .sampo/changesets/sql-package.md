New `@okikio/sql` package: typed PostgreSQL tables, expressions and statements without SQL strings. Tables are defined once and give typed column expressions, `create table` statements and indexes. `select`, `insert`, `update` and `delete` compile to `$1` text with values and to template pieces, so Postgres.js, pg, Drizzle, Kysely and Prisma can all run them through a one-method executor. Each type fixes how its value is sent and read, so every client returns the same values. `render` and `describe` let tests compare statements with committed SQL and with an installed schema. Named subqueries, `update … from`, `delete … using`, `insert … select`, filtered counts and row numbers keep multi-step work in one statement. An executor can cancel a statement through an abort signal, and a database can open a transaction at a chosen isolation level. `choose` writes `case`, `distinct` and `same` compare with NULL as a value, and `aggregate` embeds a one-row aggregate subquery. `trigger` builds trigger functions and triggers from typed steps, and the DDL helpers add `bigserial` and `gin` indexes, backfilled columns, `set not null` and replaced checks.
